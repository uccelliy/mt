如果transformer在认知测试上失败，这代表了什么，代表了一些认知能力的缺陷吗？为什么我们会认为LLM有认知能力呢？根本没有认知能力和有这种能力但是不够好一样吗？为什么会没有或者说不够好，能不能找到因果解释？
许多心理学任务无法使用语言良好表达，当然表格数据也无法表达，更多时候是视觉听觉多种输入。语言模型是否合适？多模态语言模型是否合适？但是现在开源模型多模态并不够多，难以增加样本量。是不是有其他方式统一输入。但是问题又回到，设计一种多模态输入处理的人工神经网络，本质上和多模态语言模型没区别，人工神经网络规模还更小，除了解释性更强没有优点。并且为啥要让模型做心理学任务这一问题依然没有回答。
根据已经看到的文章，让模型做心理学任务主要目的是为了foundation model这一目标。但是认知基础模型由于是对人类认知进行模拟，和其他领域如分子领域有所不同，人类认知也没有一个相对锚定的目标，你不能说在任务上表现好就是个好的模型。目前研究已经从不局限于模型的表现好，而更近一步的探讨模型是否更好的模拟人类认知，更像人，也就是模型人类对齐。cogbench就是从模型在认知任务的行为签名上与人类进行对齐，并且很多模型也会进行生物学对齐，比如与脑指标对齐，发现网络某些功能与人脑或动物的脑指标相似。
综合来看，认知任务上行为签名对齐是目前最好做的部分，而cogbench的行为签名对齐是对于特定任务集的行为签名，比如决策任务中的决策偏好，go/nogo任务中的抑制能力。这又会回到第一段的问题，因为cogbench等一系列研究已经发现llm的决策偏好和人类有可比性所以也不会被强烈质疑。如果是抑制能力，工作记忆容量，等等认知能力，是否在llm存在都是一个问题。这个时候让模型去做go/nogo任务，nback任务本身就是没有理由的。
所以这个benchmark不能够随便去给一个不声称自己是认知模型的任务去做，只是给声称自己是认知模型的模型去做，因此我们引出第一个设计原则，我们的任务适用于不同的模型，这涉及到任务表征，向RNN还是LLM还是其他的模型都要可以实现。
由于模型的可变性，对于同一任务有不同的输入表征，这回降低可比性，这就需要一个相对确定的结果指标来比较，比如在图像识别领域，图像识别的准确率就是一个锚定的指标，不论模型如何处理图像只要图像识别率够高就行。我们是否可以借鉴这种指标，定义出一种相对确定的行为签名指标来比较不同的模型，这样我们就是使用同一任务去测试不同的模型来比较到底哪一个模型更好的。
但是行为签名其实还是多种多样的，你可以说是反应时，也可以说是更底层的人类特性，比如人类的高度元认知能力，组合学习能力，因果推断能力。因此这至少应该是可拓展的，不知道未来要如何就不要现在锚定。元认知能力可以通过改变任务的环境来简单推断，组合学习能力和因果推断能力可以通过操纵任务设计来测试，但是这种都属于改变任务的格式，与上文提到的为不同模型进行不同方式的表征重叠会让复杂度大大提高。
评估认知基础模型这一想法现在本身是不可行的，或者说无法作为一个独立的研究问题。因为这一领域通用模型只有一个centaur，没有其他可比较的对象，更可行的是建立一个新的模型并提供初步的评估框架。
目前可以想到的就是将反应时纳入模型中，此时问题就成为怎么讲反应时纳入模型中？以训练目标的形式吗？还是以模型本身计算资源为限制？甚至是以提示词为限制？这些都属于方法的变体，他们应该对同一个目标进行解释，这个目标其实就是反应时究竟意味着什么，因为对反应时建模，就要思考反应时对人类认知的作用究竟意味着什么？但是要注意到这些方法的不同本身也对不同的机器学习问题有贡献，因此也需要提前想清楚为什么要使用这些方法，而不是异想天开。

## 0. 这份文档是什么，不是什么

**是**：把已跑完的初步评估结果收拢成一处，并记录由结果引出的、尚未确定的探索方向。

**不是**：

- **不是 benchmark 设计文档**。那份文档的要求是"照着就能施工"——评估主题、轴、指标定义、协议条款、参照系、判分规则都要可执行。它尚未开始，本文档是它的上游材料，不是它的草稿。
- **不是论文草稿**。本文档中所有结论均为初步，且尚未确定这些工作在回答什么问题、贡献如何表述——见 §8。
- **不是关于 Centaur 的评价**。所有对比的目的是标定测量工具，Centaur/Minitaur 与 Llama base、计数基线在此处是同一个角色：参照点。

**数字的使用边界（重要）**：本文档全部数字来自 `Minitaur-8B` checkpoint、runtime NF4 量化、teacher-forced 打分。它们**不是** Centaur-70B/BF16 论文结果的复现，不得与论文数字相减，也不得作为对外参考值引用。E0 / P0 / E3 三条轨道的 scalar 各有不同口径，彼此之间同样不能直接相减。

## 2. 从结果读出的四条观察

### 2.1 优势分解：约 98% 来自通用预训练 + ICL

以经验 uniform（1.6096）为原点的瀑布：

```
uniform 1.6096
  → Llama base full            −0.694 nat   （通用预训练 + ICL；其中 bigram 可达部分 0.341）
  → Minitaur full              −0.014 nat   （Psych-101 行为微调）
```

行为微调增益 = **0.0142 nat**（task 级配对 95% 正态近似 ±0.0037），**75/75 任务全部为正**。论文口径同样成立：36-family `official_eval_loss` 均值 Llama 0.5863 vs Minitaur 0.5727，增益 0.0136，**36/36 family 全为正**。

即：真实、普遍、但极小。相对简单基线的优势约 98% 来自通用能力，约 2% 来自行为微调。

### 2.2 优势与序列统计高度相关

逐任务的 Minitaur 总增益与 bigram 增益相关 **r = 0.79**。模型赢得最多的任务，恰是纯计数序列统计也能薅到最多的任务。赢 bigram 最多的多为答案可从上下文直接读出或推出的记忆/复述类任务（`enkavi2019digitspan`、`popov2023intent`、`garcia2023experiential`、`krueger2022identifying`）——那是上下文抽取。

### 2.3 干净战场上优势归零或为负

在序列统计薅不到东西的独立 trial 任务上，三个旗舰任务全部输给**经验** uniform：

|任务|Llama base|Minitaur|经验 uniform|
|---|--:|--:|--:|
|`wulff2018description`|0.947|0.838|**0.582**|
|`ruggeri2022globalizability`|—|0.712|**0.665**|
|`hebart2023things`|—|1.148|**1.091**|

（经验 uniform 按 session 实际出现的标签集大小算，低于理论 ln K；这是 2026-07-27 的勘误，修正后结论更强。）

18 个独立任务整体上 Minitaur 仍平均领先 0.26 nat，因此不能说优势"全是"表面统计；但在最能检验认知机制的地方，优势最薄。

### 2.4 微调增益的结构：集中在 trial 0，且与序列统计无关

- trial-0 macro NLL：Llama 3.19 vs Minitaur 2.75，差 **0.44 nat**；从 trial 1 起差距骤降到 ~0.01–0.02 并保持
- corr(微调增益, bigram 增益) = **−0.06**（对照总优势的 r = 0.79）
- 微调增益最大的恰是独立 trial 任务（`wulff2018description` 0.109、`ruggeri2022globalizability` 0.049、`wulff2018sampling` 0.043）

**读法**：微调学到的东西大部分等价于一个被压缩的格式 / 反应空间先验，一个 trial 的 ICL 几乎可以完全替代。方向上符合"学到了行为先验"，但即便加上微调，两模型在 §2.3 的三个任务上仍全部输给经验 uniform。

E3a 的合法标签重归一化诊断可以判定这 0.44 nat 里有多少只是"合法按键先验"；在它跑完之前，上述读法是**假设**而非结论。

### 2.5 四条合起来

四条观察指向同一件事：**aggregate held-out NLL 主要在度量"人类选择从上下文中的可抽取性"，而不是"对认知的建模质量"。** 而且它在两个本质不同的模型（为认知训练 vs 未为认知训练）之间只有 0.014 nat 的动态范围。

## 3. 一个由此引出的猜想（待检验）

把 §2.2 和资源维度放在一起：更强的上下文抽取能力 → 更低的 held-out NLL → 更高的分数，同时离有限的人类认知**更远**。

**猜想：沿资源维度，预测性 NLL 与认知保真度是反相关的。** 超人的记忆会系统性地抬高该指标。

标注为猜想而非结论：目前只有 r = 0.79 这一条间接证据，尚无同时测量"资源画像"与"指标得分"的实验。§6 中的 lag-profile 与资源签名探索是检验它的直接路径。

## 4. 两条已确定的前置立场

在任何 metric 定义之前需要声明的两件事，目前已定：

### 4.1 分析层次：人群后验被摊销进参数

经典认知建模中个体差异住在参数 θ_i 里，人群是 θ 上的分布。在单 checkpoint 的 LLM 中，一套权重要交代所有参与者，因此**人群后验被摊销进了权重，个体差异只能由上下文承载**。这是一个隐含但很强的理论承诺：网络需要从 transcript 前缀里在线推断 θ_i 并隐式条件化。

**推论**：单个 Centaur checkpoint 更准确的描述是"人群层面的摊销后验"，而非"一个个体"。要让"模型 = 处于人群分布中的个体"字面成立，个体化步骤必须显式化（按参与者 conditioning、按参与者适配、或一个被采样的 latent）。

**尚无人验证这个摊销是否真的发生。** 这直接产生 §6 的探索方向 A。

### 4.2 资源立场：substrate free / signature matched

- **描述层面**：这些模型拥有无界、内容寻址、不衰减的 transcript 访问；没有干扰、没有容量上限、没有遗忘曲线。这远离人类分布，且任何行为微调都挪不动它。
- **规范层面**：不采纳"资源可以是任何东西，只看输出"。在有限理性 / resource-rational 传统里，资源限制本身就是理论——它解释了行为为什么长这个样子。复现人类选择而拥有无界记忆的系统在 Marr 的计算层面是对的，在其下的层面是错的。
- **采纳的立场**：**底层基质不需要具备人类的资源限制，但有效策略必须表现出人类的资源签名。** 无界上下文可以接受；表现得像"lag 20 的信息与 lag 1 一样可得"不可接受。

因此资源类的检验是**行为签名匹配**，不是架构匹配。

## 5. 结构性盲区：现有全部结果都是 teacher-forced

E0 / P0 / E1 / E3 / E5 全部是 teacher-forced 逐 token NLL；E2 是 prequential 计数。**每一个数字都是 one-step-ahead 预测。**

两个后果：

1. **原理上测不到任何"维持"类的容量限制。** teacher forcing 每一步都把正确历史喂回去，维持的需求被彻底消除。这不是精度不足，是构念上的失明。
2. **看不见自由运行下的行为。** 认知模型的立身之本是模拟；"NLL 漂亮但自由生成崩掉"这种情形完全落在盲区内，因为 teacher forcing 阻止了误差累积，模型永远不必自己维持一个可信的状态。

**一个已在数据中的例证**：`enkavi2019digitspan` 是 Minitaur 赢 bigram 最多的任务之一。人类的数字广度约 7，而模型在这个任务上表现好，恰恰因为**它不需要广度**——数字就写在可见上下文里。这不是超人的工作记忆，而是这个任务对它根本不构成工作记忆任务。

**一个概念澄清**：读取完整 transcript 的 full-attention transformer 在心理学意义上没有工作记忆；它有的是一个**外部存储**（context）加一个**检索过程**。"WM 容量是否会涌现"这个问法因此需要改写为：**模型的检索-整合过程是否表现出在行为上模仿人类 WM 限制的限制？**

## 6. 探索方向（均未确定，按可行性排序）

以下四条是从 §2–§5 引出的候选，尚未决定哪些进入未来的 benchmark，也尚未确定它们各自在回答什么科学问题（见 §8）。

### 6.1 零算力可做（依赖 Llama base 的 E3）

**Minitaur vs Llama base 的 lag-sensitivity profile 对比。** 两条 E3 窗口曲线直接相减。若两者近乎重合，即为"Psych-101 行为微调没有安装任何资源结构"的直接证据（结合 §2.4，这是当前的预期）。同时它就是 E5 交互项的一个解释性读法，无需额外算力。

**按记忆负荷分层看 lag profile。** 高记忆负荷任务（digit span 等）与低负荷任务的曲线形状是否分化。若完全不分化，说明模型对"这个任务需要记住东西"没有任何表征。

**full − w20 残差对位置/长度的回归**（design §7.5 已列为 E3b 的重启前置）。

### 6.2 方向 A：individuation gain —— 个体差异到底有没有被表征

**问什么**：§4.1 的摊销承诺是否真的发生。

**怎么测**：`individuation gain` = NLL(匹配的他人历史) − NLL(自己的历史)，画成历史长度的函数。三种诊断形状：

|形状|读法|
|---|---|
|随历史长度增长|真正的摊销式个体推断，在累积关于"这个人"的证据|
|平坦且接近零|只推断了**任务**；个体差异未被表征，所有"建模某参与者"实为建模平均人|
|非零但平坦|第一个 trial 抓到风格/格式签名后再未细化|

**参照系**：层级贝叶斯认知模型的"群体层后验 vs 个体层后验"在留出 trial 上的预测差。注意这里的关键区分——拟合的认知模型**不能**作为绝对 NLL 的 ceiling（它在绝对 NLL 上已经输了，且任务-模型对应关系不统一），但 individuation gain 是一个**差值**，对差值而言认知模型是合格参照：它告诉你该任务里到底存在多少可获得的个体信号。

**现状**：E3a 已设计了 `matched other-participant` 条件（design §7.4）。此方向只需把它从"E3a 的一个对照"升格为独立测量。

### 6.3 方向 B：lag-profile match —— 资源签名是否与人类匹配

**问什么**：§4.2 的 signature-matched 立场怎么落地。

**怎么测**：模型侧 = E3 的窗口曲线；人类侧 = 从人类选择数据独立估计的"对 lag k 信息的依赖程度"。比较**曲线形状**而非绝对值。

**为什么比单独的 E3 强**：E3 单独不能读成抽象记忆跨度（截断同时改变可见内容、输入长度与 transcript 连贯性——这一 caveat 在 handoff §5 中是正确的）。但匹配版本的识别性好得多，因为截断带来的混淆只作用于模型侧，人类曲线是独立估计的。

### 6.4 方向 C：资源签名的正交设计 —— 人类式容量 vs 注意力稀释

**问什么**：模型确实有某种软性限制（softmax 稀释、位置偏置、长上下文检索退化），但索引变量可能是错的。

||人类 WM|LLM 软限制（预期）|
|---|---|---|
|由什么决定|项目数 / chunk 结构|token 距离、总上下文长度|
|干扰来源|相似项的语义干扰|位置稀释、注意力分散|
|组块效应|强（7 chunks 而非 7 items）|基本没有|
|set-size 函数形状|平台到 K 后陡降|平滑渐进衰减|

**怎么测**：2×2 正交化——固定待记忆项目数、只改 token 距离（无关 filler 填充）；固定 token 距离、只改项目数。人类式签名 → 对项目数敏感、对 filler 不敏感；稀释式 → 反之。附加判据：set-size 函数的**形状**（平台-陡降 vs 平滑衰减）本身即可区分两种机制，且不需要绝对参照系。

**实现**：可建在 E3 已有的分段 / `build_window_prompt` 机器上，改动量小。

**配套的区分实验**：直接 prompt"你的记忆有限"就能让模型演出容量限制，这是与机制脱钩的平凡版本。判别方法——**模仿出来的签名会瞬间出现、跨任务均一、且随 prompt 移除而消失**；结构性限制应随任务结构变化且对表面措辞稳健。E4（语言表面扰动）是这个的载具。

### 6.5 方向 D：现象重现 / simulation adequacy

**问什么**：§5 的盲区。模型能不能**重现现象**，而不只是拟合数据。

**怎么测**：自由生成（非 teacher-forced）一批合成参与者，检查该范式的标志性定性效应是否出现、符号是否正确、量级是否落在人类区间。

**为什么绕开了 ceiling 问题**：效应的方向与量级有人类经验值可对照，不需要估计单 trial 选择的不可约熵。

**代价**：最贵，需要新增自由生成能力（runner 与聚合都要新写）。但它填的是最大的洞。

**与截断的关系**：在文本设置里，要让材料"离开可见上下文"，操作化恰好就是 E3 的截断。因此 window 机制可视为"从存储中移除项目"的合法实现，lag 曲线即遗忘曲线。

## 7. 一条工作判据（暂定）

选轴时的经验规则，暂记于此，尚未验证其普适性：

**一个评估轴有没有价值，看它在参照模型阶梯上的分离度，而不看它好不好算。**

参照阶梯：经验 uniform → 计数基线 → Llama base → Centaur/Minitaur → 拟合认知模型 →（人类一致性上界，若可得）。

用它回看：aggregate NLL 在 Llama base ↔ Minitaur 之间只有 0.014 nat 的动态范围。

推论：**没有分离度的轴，同时也是给不出训练信号的轴**——这条对自建基础模型是同一判据。

## 7B. 由官方数据引出的新方向与未解现象（2026-07-29）

本节的四项均**不属于当前 evaluation 的执行范围**：前两项是尚无解释的现象，
后两项是尚未定型的研究方向。相关的实证结果本身写在 handoff §5 与
design §3.1，此处只记录"不知道为什么"和"可能怎么做"。

### 7B.1 未解现象一：三个任务的领域认知模型输给群体计数

E2-pop（规范空间的群体计数基线，协议与论文认知模型完全一致：训练参与者拟合、
held-out 参与者打分）在 19 个可干净比较的 family 上，有 3 个的官方认知基线
**输给纯计数**：

| 任务 | 补充材料指定的模型 | 认知基线 | 群体计数 |
|---|---|---:|---:|
| plonsky2018when (CPC18) | 前景理论 | 0.661 | **0.475** |
| peterson2021using (choices13k) | 前景理论 | 0.656 | **0.582** |
| ruggeri2022globalizability | 双曲折扣 | 0.659 | **0.640** |

**已排除的解释**：曾猜测是"缺 perseveration 项"，但补充材料显示 RW（模型 5）
显式含短期粘着 $b$ 与长期选择频率 $c$；且这三个任务用的是前景理论/双曲折扣，
均为独立试次的价值型选择，perseveration 本就不适用。该假设作废。

**尚存的候选解释**（均未检验）：

1. 特定参数化形式失配——补充材料的前景理论采用的不是常见的累积前景理论
   概率权重函数，双曲折扣也只有 $a,\beta$ 两个参数；
2. 联合估计一套参数的代价——在个体差异大的价值型任务上，单一参数集可能比
   "只记住群体边际比例"更差；
3. 口径问题——需先确认这些任务 canonical `choice` 列的语义（是"选了 A/B 位置"
   还是"选了风险/延迟选项"），语义不同则群体 base rate 的含义完全不同。

**在查清之前不得写进论文。** 若解释 2 成立，它与 §7B.2 是同一件事的两面。

### 7B.2 未解现象二：认知模型在会话内是平的

fig15 显示认知基线的 NLL 在 session 内几乎不变（decile 0: 0.7126 → decile 9:
0.7174），而 Centaur 从 0.6547 降到 0.4203、未微调 base-70B 从 0.9470 降到
0.5322。

关键在于：**认知模型并非没有会话内更新**——RW 更新价值、GCM 累积样例、GP-UCB
更新后验。它们本应随着参与者学会任务而变得更准。平坦意味着人类在会话后期确实
变得更可预测（两个 LLM 的曲线都证明了这一点），而**认知模型没能捕捉到这个
可预测性的增长**。

可能的成因（未检验，互不排斥）：

1. **状态更新到位但参数不到位**：价值在更新，但学习率/温度是全体共用的一套，
   无法跟上个体的学习速度差异；
2. **模型族本身的天花板**：RW 类模型的预测在收敛后趋于常数，而人类后期的
   可预测性增长来自策略固化/规则发现等 RW 不表达的过程；
3. **评估口径**：若后期 trial 的选项集或难度分布系统性变化，平坦可能部分是
   任务设计而非模型缺陷——需逐任务查。

这个现象值得单独成一个小结果：**它是"认知模型缺什么"的直接指标**，而且不需要
任何新的模型拟合就能观察到。若成因 1 成立，则它同时解释 §7B.1。

### 7B.3 方向：预测能力与模拟能力的可分离性

**初始表述（用户提出）**：能模拟人类认知的模型必能预测人类反应，但能预测的
不一定能模拟。即嵌套关系：模拟 ⟹ 预测。

**建议修正为可分离（2×2），而非嵌套**。理由：前半句在本项目的证据下不成立。
一个机制完全正确但在**群体层面**拟合的认知模型，在 teacher-forced NLL 上会
输给做在线个体识别的 LLM——这正是 §3.1/fig15 观察到的事实（trial 0 上认知
模型胜出，随历史累积被反超）。

| | 模拟差 | 模拟好 |
|---|---|---|
| **预测好** | LLM / Centaur（现有证据指向此格） | 目标 |
| **预测差** | — | 群体拟合的正确认知模型 |

可分离版本更强：它预言存在"预测差但模拟好"的模型，而这正是第三阶段要构造的
对照；嵌套版本则无法解释认知模型为何在 NLL 上落后。

**已有的支持性证据**（均为预测赛道内部的症状，不能替代模拟赛道的直接测量）：
干净战场上模型输给经验 uniform；wulff/ruggeri 的校准失败（置信度无信号支撑）；
优势与 bigram 可利用性相关 r=0.78；fig15 的位置依赖。

**文献定位**（供撰写时引用，Crossref 已核对）：

- **Palminteri, Wyart & Koechlin (2017), *TICS*, "The importance of falsification
  in computational cognitive modeling"** [10.1016/j.tics.2017.03.011] — 论点即
  拟合优度不足以验证模型、必须用模拟证伪；本方向的直接前身，必读。
- Shmueli (2010), *Statistical Science*, "To explain or to predict?"
  [10.1214/10-sts330]
- Yarkoni & Westfall (2017), *Perspectives on Psychological Science*
  [10.1177/1745691617693393]
- Wilson & Collins (2019), *eLife* — 模型/参数可恢复性的操作规程。

**贡献边界**：这个区分本身已有文献，新的部分只可能是"在一个具体基座模型上
**量化**这个 gap 有多大"。撰写时不得把区分本身声明为贡献。

### 7B.4 方向：P500 + Psych-101 的能力画像

**素材**：P500 为人类被试数据，原始为表格，已转换文本（`../p500-100agents`）。
`instruments.csv` 含**完整任务规格**——序列生成规则、时序参数、自适应阶梯
配置（如 Flanker 的 `StepSize/NUp/NDown/MaxResponseTime` 单阶梯、AX-CPT 的
`ItemSequence`）。这不只是数据，而是一个**任务引擎的规格**。

**互补性成立**：Psych-101 重决策/RL/记忆，几乎没有抑制控制、干扰解决、任务
切换；P500 的 Flanker、AX-CPT 类任务正好填这个空白。不是覆盖重复。

**三个必须先定的设计问题**：

1. **必须是 open-loop，否则自我否定**。若仍做 teacher-forced 打分，测的还是
   预测，§7B.3 的整个论点落空。让模型自己选择、自己接收反馈、跑完整轨迹，
   再测行为表型（即 design §4.3/§8 的第三阶段）。
2. **执行功能任务的主变量是 RT，不是 choice**。Flanker 效应是"不一致条件下
   慢多少毫秒"。而现有评估口径是 choice-NLL，自然语言 transcript 处理 RT 很
   笨拙。这是合并两个数据集最大的技术障碍，需先定 RT 如何进指标。
3. **能力缺口分析必须依托现成本体，不能凭直觉**。建议用 Miyake 的执行功能
   三成分（抑制/更新/切换）或 Cognitive Atlas 之类的任务本体，才谈得上
   "覆盖了 X、缺 Y"。

**最有价值的单点抓手：自适应阈值的 open-loop 测量。** 让模型跑进 P500 原本的
staircase，用它自己的反应驱动难度调整，看阈值收敛到哪里——直接产出与人类可比
的心理测量学参数（Flanker 干扰量、AX-CPT 的 $d'$），而不是又一个 NLL 数字。
Psych-101 给不了这个（只有渲染好的 transcript），P500 的表格 + 规格给得了。
如果 benchmark 只做一件事，建议就是这个。

**范围提醒**：这是与当前工作不同体量的另一个项目。当前工作产出的是"NLL 作为
认知相似性指标是否有效"的方法论结果；benchmark 是基础设施型贡献，评价标准
不同。建议当前论文封口后再展开。
